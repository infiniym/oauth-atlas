## Changes

- A continuation explicitly reads the supplied documentation even when it has saved sources and a draft. It invalidates the affected interpretation checkpoint, preserves confirmed answers and saves a new version. Targeted repair uses the recovery URL and reads only that source. An unreadable supplied source fails specifically rather than quietly reusing only old evidence.
- Reviewed Gmail, Slack and GitHub actions include concrete backend JavaScript requests, test inputs, source links, expected responses and safe boundary guidance. The code uses an authorized Composio session's documented proxy. It needs the Project API key's Proxy execute permission; it does not expose provider tokens.
- Live curl commands quote their arguments so query strings survive zsh expansion. Required version headers use explicit documentation examples; resource IDs and tokens remain test inputs. Applying guide fixes can update old examples in a new version without model calls.
- Personal checkmarks advance the highlighted action; unchecking reverses it. A blocked first test does not advance to customer launch. Completion remains the developer's local report and never changes saved verification.
- Confirmed actions, audience, stage and route appear near the heading. The original description is labeled separately, so editing actions cannot silently make an old description appear authoritative.
- Launch tasks are collapsed initially. Requirements attach to their canonical checklist row; the managed-fit task is no longer repeated as a launch gate. Verification tasks appear beside their step. Font and other static-asset failures do not become provider follow-ups.
- Markdown retains request code, integration code, administrator timing, applicability and reported resolution. Personal checklist marks remain excluded.
- A format-only repair can shorten oversized model instructions once, under the same action deadline, with the same evidence. It does not repeat research or bypass validation. The first real Dropbox recovery exposed an overlong server-generated input field; the field was corrected. A subsequent attempt exposed oversized model prose, motivating the bounded format repair.
