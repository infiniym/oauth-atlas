# Diagnostic boundaries

The original `38160c9` control and all candidate attempts are retained. Full model/source traces are ignored local diagnostic files; the tracked evidence contains the original inputs, final quotations, source identities, observed errors and per-stage metrics. No signed model reasoning or credentials are included.

| Reproduced failure class | Shared correction | Regression |
| --- | --- | --- |
| A valid relative/template endpoint was rejected as a documentation destination | Separate API route/host/query grounding from documentation links, with a precise rejected field | `completion: documented relative route templates…` and grounding tests |
| Pagination requests collapsed under a shared action | Reconcile only identical requests; preserve distinct continuation steps | Distinct pagination request fixture and request-stub inspection |
| Formatting failure mistaken for permission uncertainty | Repair only malformed/long presentation fields, then revalidate; numeric review IDs | Length and independent-review fixtures |
| Localized copies consumed source budget; OAuth app registration absent | Deduplicate equivalent locale/redirect paths; select registration and endpoint evidence separately | Locale/source coverage fixtures and real OpenProject records |
| Retrieved operation omitted by tied resource ranking | Keep distinct retrieved operation references ahead of generic schemas | Distinct operation fixture |
| Required version and simple default scope omitted by compressed context | Prioritize protocol constants and scope declarations, including ordinary names and table rows | Version and simple scope fixtures |
| Response JSON crowded out the requested nested route | Rank documented method/routes by requested resource terms before example JSON | Nested-route fixture |
| Personal/CI token example copied into OAuth guide | Reject incompatible authentication and require documented OAuth token handling | OAuth-header fixture |
| Navigation selected source-editing UI, unrelated token administration, or other doc versions | Exclude editor/history controls; distinguish token administration from OAuth setup; keep one documentation version | Navigation/coverage fixtures |
| Initial medium-effort generation exhausted output/time budget | Same model and full contract at low effort for final assembly; independent permission review stays medium; one concise retry within the existing budget | Bounded output recovery fixture and measured fresh jobs |
| Client stream stayed open after saved completion | Saved-job polling runs alongside the stream, without starting duplicate work | Stalled-stream fixture and real disconnect/reopen record |
| Production local model bindings were absent | Resolve the ignored root `.dev.vars` path explicitly in `npm start` | Actual local startup and fresh HTTP checks |
| Parser classified empty boundary text or incomplete pages as a handoff | Require a concrete continuation and stopping condition, a useful safe boundary check and independent review of the whole request | Pagination/boundary fixtures; v16/v17 source review notes |
| Actual curl differed from endpoint metadata or used unnormalized sample IDs/instance hosts | Parse the command and ground actual method, host, path and query; normalize inputs only at documented route-variable positions | Actual-example, sample-ID, next-Link and instance-input fixtures |
| A stalled response body ignored a fired stage deadline | Cancel the reader on abort and apply the same per-call deadline to headers and body | Stalled-body cancellation fixture and retained v18 timeout |
| An unstructured response or malformed row consumed full-guide retries | Compact grammar-constrained output with mandatory citation slots; bounded row-only repair preserves every nonempty string | Compact transport and value-preserving repair fixtures |
| Access review omitted setup or pagination/response field context | Include setup steps, exact requests, inputs, end conditions, response aliases and cited boundary context | Review-input and context-priority fixtures; original rejections retained |
| Broad named scopes were confused with unscoped OAuth | Require the actual named/default grant in action mappings; only genuinely unscoped grants use an empty list | Named broad scope review fixture and v19 manual source finding |
| A failed interpretation checkpoint was reused as completed planning | Persist acceptance explicitly, omit failed drafts, retain evidence/answers and strip old engine metadata | Failed-stage retry and resumed-review fixtures |
| An action repair could not correct its existing continuation | Return bounded updates for all affected requests in one action, retaining IDs/dependencies and unrelated actions | Multi-request repair, old-snapshot and continuation fixtures |
| A full named schema exceeded the model grammar budget, while positional rows repeatedly lost columns | Split facts and requests into smaller named contracts; retain the same complete local validation and independent review | Named-contract fixtures and saved real schema probes |
| A failed request-stage checkpoint erased already validated facts | Carry accepted facts through subsequent saves; clear them when documentation is explicitly replaced | Failed named-stage retention and resumed-step fixtures |
| Narrative guides displaced concrete operation references; operation summaries were absent from review | Select request/setup/support links separately, prioritize exact operations and retain operation summaries beside request parameters | Navigation-index, root-parameter tutorial and operation-summary fixtures |
| Optional query parameter silently restricts the requested collection | Read the operation's exact unfiltered-value contract and validate the concrete request; do not inherit an unrequested default subset | Default-filter fixture and OpenProject v34/v36 records |
| A small response example was mistaken for a closed object schema | Resolve explicitly linked object references only when their literal response-type discriminator matches this operation | Linked-reference fixture, including missing-link, mismatched-type and unrelated-operation negatives |
| An OAuth error sample was attributed to an earlier GraphQL request | Recognize absolute HTTP request lines and exclude error-only samples from success-response contracts | Error/absolute-operation fixture and Linear v36 diagnosis |
| Independent review approved a grant without completing the rest of the handoff | Require separate setup, grant, request, response, pagination and boundary checks; retain unresolved criteria and affected step IDs | Conflicting verdict fixture and real review output |
| Action recovery received a smaller source contract than initial planning | Use the same operation/property context in planning, review and action repair | Context regressions and retained original failures |
| Temporary network error immediately ended public reading | Retry the same validated address once within the existing job budget and show the retry; never retry unavailable pages or bypass public-address validation | Transient-read and HTTP 404 fixture |
| Segmented text and direct children were presented as complete content | Require complete text-segment extraction and documented nested traversal or another complete representation | Completeness fixture and Notion v37 manual rejection |
| Setup correction silently excluded the third affected prerequisite | Retain up to four explicitly affected setup/boundary steps and one consistent client type | Three-step correction fixture and Forgejo v37 |
| Common-plan compatibility read published an accepted partial guide | Apply the shared usable-guide predicate before creating a plan, preserving existing frozen rows | Common-plan completeness and immutability fixture |
| An instance placeholder in endpoint metadata triggered needless model retries | Normalize the canonical instance input to a relative metadata route; independently ground the route, query and executable URL | Authorization metadata fixture with an undocumented-route negative |
