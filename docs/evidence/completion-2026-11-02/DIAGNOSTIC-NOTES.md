# Diagnostic boundaries

The original `38160c9` control and all candidate attempts are retained. Full model/source traces are ignored local diagnostic files; the tracked evidence contains the original inputs, final quotations, source identities, observed errors and per-stage metrics. No signed model reasoning or credentials are included.

| Reproduced failure class | Shared correction | Regression |
| --- | --- | --- |
| A valid relative/template endpoint was rejected as a documentation destination | Separate API route/host/query grounding from documentation links, with a precise rejected field | `completion: documented relative route templates…` and grounding tests |
| Pagination requests collapsed under a shared action | Reconcile only identical requests; preserve distinct continuation steps | Distinct pagination request fixture and request-stub inspection |
| Formatting failure mistaken for permission uncertainty | Repair only malformed/long presentation fields, then revalidate; numeric review IDs | Length and independent-review fixtures |
| Localized copies consumed source budget; OAuth app registration absent | Deduplicate equivalent locale/redirect paths; select registration and endpoint evidence separately | Locale/source coverage fixtures and real OpenProject records |
| Retrieved operation omitted by tied resource ranking | Keep distinct retrieved operation references ahead of generic schemas | Distinct operation fixture |
| Required version and simple default scope omitted by compressed context | Prioritize protocol constants and scope declarations, including ordinary names and table rows | Version and simple scope fixtures |

| Personal/CI token example copied into OAuth guide | Reject incompatible authentication and require documented OAuth token handling | OAuth-header fixture |
| Navigation selected source-editing UI, unrelated token administration, or other doc versions | Exclude editor/history controls; distinguish token administration from OAuth setup; keep one documentation version | Navigation/coverage fixtures |
| Initial medium-effort generation exhausted output/time budget | Same model and full contract at low effort for final assembly; independent permission review stays medium; one concise retry within the existing budget | Bounded output recovery fixture and measured fresh jobs |
